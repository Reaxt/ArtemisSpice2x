# AremisSpice2x
an artemis plugin for Spice2x

Setup is super simple, just put in the api url and port, and enable the API in spice's config launcher. 

This has been hacked together in a night, so its not super clean and may have some bugs. 
I both referenced, and directly took a bit of code from [https://github.com/diogotr7/Artemis.Plugins](https://github.com/diogotr7/Artemis.Plugins), so huge shoutouts to diogotr7, (given yknow, theres basically no documentation for making plugins in artemis still..)
